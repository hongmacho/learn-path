서비스 소개

런패스는 개발자와 학습자가 자신의 학습 경로를 직접 설계하고, 진도를 추적하는 개인 학습 관리 도구입니다. Rust 언어 학습, 데이터 구조 마스터, 클라우드 인프라 습득 등 명확한 목표를 가진 학습 여정을 체계적으로 관리하고, 복습 예정일을 자동 계산하여 효율적인 학습을 지원합니다.

주요 사용 시나리오

1. Rust 학습 경로 설계

"Rust 입문" → "소유권 이해" → "라이프타임 정복" 등 세부 학습 단계를 정의합니다. 각 단계별 학습 자료, 예상 소요 시간, 진도율을 추적합니다.

2. 복습 예정일 관리

간격 반복(Spaced Repetition) 원리에 따라 학습한 내용의 복습 예정일을 자동 계산합니다. "내일 복습", "3일 후 복습" 등 제안받습니다.

3. 학습 진도 추적

각 학습 항목의 완료 여부, 난이도, 이해도를 기록합니다. 월별/주별 학습량 통계와 진도율을 시각화로 볼 수 있습니다.

추천 사용법

1

학습 목표 정의

예: "6개월 안에 Rust 완전 숙달" 또는 "React 고급 패턴 마스터"

2

학습 경로 분해

대주제를 작은 학습 단계로 나눕니다. 각 단계마다 학습 자료 링크를 저장합니다.

3

일일 학습 기록

매일 학습한 항목을 체크하고, 이해도(1-5점)를 입력합니다.

4

복습 일정 확인

앱이 자동 제안하는 "오늘의 복습"을 확인하고 복습합니다.

5

진도율 분석

주별/월별 학습량, 완료율, 평균 이해도를 대시보드에서 확인합니다.

알려진 한계점

  • • 단일 커리큘럼: 현재는 사용자가 커리큘럼을 직접 만들어야 합니다. 기본 템플릿(Python, JavaScript 등)은 아직 미제공입니다.
  • • 커뮤니티 기능 부재: 다른 학습자와 경로를 공유하거나 함께 학습할 수 있는 기능이 없습니다.
  • • AI 추천 미지원: 학습 경로 최적화나 개인화 추천 기능은 추후 추가될 예정입니다.

향후 개선 제안

1. 오픈소스 커리큘럼

커뮤니티가 만든 검증된 학습 경로 템플릿을 제공합니다. "초급 Rust", "Advanced React", "ML 기초" 등 한 클릭으로 로드 가능.

2. AI 기반 최적화

학습 진도와 이해도를 분석하여 약점 영역 복습을 자동 제안합니다.

3. 학습 일정 공유

학습 경로를 팀원이나 멘토와 공유하고, 피드백을 받을 수 있습니다.

빠른 시작

https://learn-path.example.com

# 2. 새 학습 경로 생성

"새 경로" → 목표 입력 → 학습 단계 추가

# 3. 매일 학습 기록

완료한 항목을 체크하고 이해도를 입력합니다.
